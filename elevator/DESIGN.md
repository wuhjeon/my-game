# 올라가는 중 — 엘리베이터 이상현상 게임 기획서

- 상태: 기획 v0.6, M3 진행 중 (실제 기기 확인 대기)
- 장르: 1인칭 이상현상 찾기 공포 (8번 출구류)
- 차별점: 수평 이동(통로) 대신 수직 이동(엘리베이터). 좁은 밀실, 문이 닫히는 시간 압박, 층 표시판이 곧 진행도
- 기술: 기존 게임과 같은 단일 `index.html` + Three.js r128, 경로 `elevator/`

## 1. 확정된 결정 (사용자 선택)

| 항목 | 결정 |
|---|---|
| 판정 규칙 | 이상 없으면 ▲, 이상 있으면 ▼ |
| 이동 범위 | 엘리베이터 안 + 문이 열려 있는 동안 그 층의 로비 (M2에서 변경) |
| 난이도 | 느긋하게 / 보통 / 어려움 3단계 (v0.5에서 변경). 어려움만 문이 닫힘. 어려움 모드 시간은 실험 중 |
| 공포 수위 | 원작 수준 + 추락 연출, 갑자기 놀래키는 장면은 1~2종 |
| 제목 | 올라가는 중 |
| 1F 이후 | 숨겨진 요소 없음. 1F에서 엘리베이터를 걸어 나와 건물 밖으로 나가면 엔딩 (M2에서 변경) |
| 관리인 NPC | 청소 관리인(회색 작업복, 모자, 청소 카트), 모든 층에 등장, 평소에는 문이 열리면 플레이어를 보고 고개만 숙임 |
| 추락 흔들림 | 어지럽지 않게 약하고 부드럽게 (M2에서 변경, 7.2 참고) |

## 2. 핵심 루프

```
[탑승 운행] → [도착, 문 열림] → [관찰, 내려서 둘러보기] → [엘리베이터 안에서 ▲ 또는 ▼] → [문 닫힘] → 다음 루프의 [탑승 운행]
```

- 한 루프 = "이번 운행 + 이번에 도착한 층". 판정 대상은 문이 닫힌 직후부터 버튼을 누르기 전까지 본 모든 것
  - 운행 중(문 닫힘 상태)에도 이상현상이 나올 수 있음. 엘리베이터만의 요소
- 문이 열려 있는 동안에는 내려서 로비를 둘러볼 수 있음. 버튼은 엘리베이터 안에서만 누를 수 있음
- 시작: B8. 목표: 1F(지상)
- 정답: 층 표시가 한 층 오름 (B8 → B7 → … → B1 → 1F)
- 실패하면 B8 엘리베이터 안에서 다시 시작. 실패 종류는 4가지

| 실패 | 조건 | 연출 |
|---|---|---|
| 오답 | ▲/▼를 잘못 누름 | 추락 (7.2) |
| 시간 초과 | 어려움 모드에서 안에 있는 채로 문이 닫힘 | 추락 (7.2) |
| 엘리베이터 놓침 | 어려움 모드에서 로비에 있는 채로 문이 닫힘 | 엘리베이터만 떠나고 로비 불이 꺼짐 (7.4) |
| 붙잡힘 | "관리인이 엘리베이터 안에" 이상현상에서 6초 안에 ▼를 누르지 않음 | 암전과 비명 (7.3) |

### 2.1 ▼를 눌렀는데 위층에 도착하는 모순

- ▼(정답)를 누르면 몸으로 느끼는 운행 방향은 아래(화면 흔들림, 모터 소리, 화살표 ▼)인데, 도착하면 층 표시는 한 층 위
- 원작에서 "되돌아갔는데 번호가 오르는" 추상화와 같은 구조. 여기서는 그 어긋남을 숨기지 않고 "이 건물은 층이 맞지 않는다"는 분위기로 이용
- 혼란 방지: 엘리베이터 안 안내문에 규칙을 명시

```
승강기 이용 안내
· 이상이 없으면 ▲ 를 누르십시오.
· 이상이 있으면 ▼ 를 누르십시오.
· 지상(1F)에 도착하면 내리십시오.
```

## 3. 시간 압박 (난이도 선택)

| 모드 | 문 열림 유지 | 시간 초과 시 |
|---|---|---|
| 느긋하게 (이상현상 확률 0.3) | 무제한 | 없음 |
| 보통 (이상현상 확률 0.45) | 무제한 | 없음 |
| 어려움 (이상현상 확률 0.6) | 12초, 층 표시판 위에 남은 시간 표시, 남은 3초부터 경고음 | 안에 있으면 오답 처리(추락), 로비에 있으면 엘리베이터를 놓침 |

- v0.5 변경: 예전 "보통"(12초)을 "어려움"으로 올리고, 문이 계속 열린 새 "보통"을 가운데에 추가
- 확률: 어려움 = 느긋하게의 2배. 예전 0.55의 2배(1.1)는 100%를 넘어 "무조건 ▼"가 정답이 되므로 0.3 / 0.45 / 0.6으로 정함
  - 무조건 ▼만 눌러 8번 연속 맞힐 확률: 어려움 0.6⁸ ≈ 1.7%, 무조건 ▲는 느긋하게 0.7⁸ ≈ 5.8%
- 남은 시간 표시: 엘리베이터 안 층 표시판 위와 로비 쪽 층 표시판 위에 초 단위로 표시. 3초 이하이면 빨간색

- 어려움 모드의 열림 버튼: 누를 때마다 +4초, 한 층에서 최대 2회 (엘리베이터 안에서만 누를 수 있음)
- 닫힘 버튼: "고장" 스티커가 붙어 있고 눌러도 반응 없음. 시간 초과 외에 버튼 없이 진행하는 방법을 막는 장치이자 소품
- 문이 열리는 동작은 약 1.2초. 타이머는 문이 다 열린 순간부터 셈
- 경고: 남은 3초부터 0.5초마다 경고음. 안에서는 열림 버튼이, 로비에서는 문 위 층 표시판 화살표가 깜빡임
- 문이 닫히기 시작할 때 문간에 서 있으면, 서 있던 쪽(안 또는 밖)으로 밀려남
- 실험용 설정: 주소 뒤에 `?open=초`를 붙이면 어려움 모드 시간을 바꿀 수 있음 (4~60초, 예: `elevator/?open=15`). 화면의 "문이 N초 뒤 닫힘" 문구도 함께 바뀜

## 4. 공간 설계

### 4.1 엘리베이터 안 (약 2.0 × 1.8 × 2.4m)

| 위치 | 기준 소품 | 비고 |
|---|---|---|
| 정면 | 양쪽으로 열리는 문, 문 위 층 표시판(화살표+층) | 플레이어 시작 시 정면 |
| 오른쪽 벽 | 버튼판(▲, ▼, 열림, 닫힘(고장), 비상벨), 정원 표시 | 상호작용 대상 |
| 왼쪽 벽 | 이용 안내, 승강기 안전검사 필증, 광고 액자 | |
| 뒷벽 | 거울(위쪽), 허리 높이 손잡이 | 거울 이상현상의 무대 |
| 천장 | 사각 조명 패널, 반투명 CCTV 돔(안에 렌즈) | |
| 바닥 | 매트 | |

### 4.2 로비 (약 5.0 × 5.6 × 2.8m, 걸어서 둘러볼 수 있음)

- 모든 층의 로비는 층 번호를 빼고 완전히 같음. 플레이어가 첫 운행에서 기준 모습을 외우는 구조
- 정면 벽: 층 표지(예: "B5"), 벽등 2개, 소화전
- 왼쪽 벽: 방화문 / 오른쪽 벽: 게시판(청소 일정, 승강기 점검, 분실물) / 오른쪽 안쪽 구석: 화분
- 엘리베이터 쪽 벽(돌아보면 보임): 문틀, 호출 버튼(▲▼), 문 위 층 표시판
- 관리인 NPC: 모든 층에서 청소 카트(양동이, 대걸레) 옆에 서 있다가, 문이 열리면 플레이어를 보고 고개를 숙임. 8번 출구의 "걸어오는 남자" 역할
  - 항상 있으므로 "관리인이 없음"도 이상현상으로 씀
- 1F만 다름: 정면 벽 가운데가 자동 유리문이고 밖으로 하늘과 거리가 보임. 관리인과 카트는 없음

### 4.3 거울 구현 방식 (M2에서 변경: 반사 렌더링 + 레이어)

- 처음에는 "가짜 방(엘리베이터 안을 한 벌 더 만들어 뒷벽 너머에 둠)"으로 계획했음
- 바꾼 이유: 로비를 돌아다닐 수 있게 되면서 거울에 문 너머 로비와 관리인까지 비쳐야 함. 가짜 방 방식이면 로비까지 통째로 한 벌 더 만들고 매 프레임 맞춰야 함
- 지금 방식: 거울 면 뒤쪽에 가상 카메라를 두고 장면을 한 번 더 그려 텍스처로 씀 (three.js 예제 Reflector와 같은 원리)
  - 가상 카메라만 보는 레이어(MIRROR_LAYER)를 따로 둠. 그 레이어에 둔 물체는 거울 속에만 나타남
  - 거울 속에만 있는 것: 플레이어 몸, 거울 속 사람, 거울 속에서만 닫힌 문
  - 원래 계획의 장점("거울 속만 따로 바꿀 수 있음")은 그대로 유지
- 비용: 거울이 화면에 보일 때만 장면을 한 번 더 그림. 해상도는 화면의 0.6배

## 5. 이상현상 설계

- 난이도: 쉬움(눈에 바로 띔) / 보통(기준을 기억해야 보임) / 어려움(시간, 소리, 가까이 가서 봐야 보임)
- 실제로 들어간 목록은 9.2 참고. 기획 단계 후보 중 아래 2개는 아직 넣지 않음
  - 문 너머가 로비가 아니라 또 하나의 엘리베이터 안: 로비 탐색이 생기면서 "들어가 볼 수 있는 가짜 방"을 만들어야 해서 보류
  - 뒤쪽 문이 열림(거울 벽이 열리며 다른 로비): 거울과 충돌이 커서 보류

### 5.1 이상현상 설계 원칙

- 한 루프에 이상현상은 최대 1개
- 플레이어가 관찰 시간 안에 볼 수 있어야 함 (어려움 모드 12초 기준). 로비 구석의 이상현상은 내려서 가까이 가면 보임
- 소리만으로 알 수 있는 이상현상은 반드시 시각 단서를 함께 둠
  - 노크: 조명이 잠깐 어두워짐 / 만원 경보: 표시판에 "만원"이 깜빡임
  - 소리를 끈 상태에서는 화면 아래에 자막으로 알려 줌 ([천장 위에서 두드리는 소리], [만원 경보음], [문 닫힘 경고음])
- 같은 이상현상은 전체 목록을 한 바퀴 돌기 전에 다시 나오지 않음 (끝없는 통로와 같은 섞기 방식)

## 6. 확률과 난이도 곡선

- 첫 운행(B8 출발)은 항상 정상. 기준 모습을 보여 주는 튜토리얼 역할
- 이후 이상현상 등장 확률 p는 난이도별로 0.3 / 0.45 / 0.6 (3장 참고, 플레이테스트로 조정)
- 진행 층에 따라 어려운 이상현상 비중을 높임 (M2에서 구현)

```
진행도 k = 0(B8) … 7(B1)
P(어려움 | k) = 0.10 + 0.05·k        → B8에서 0.10, B1에서 0.45
P(쉬움 | k)   = 0.45 − 0.05·k        → B8에서 0.45, B1에서 0.10
P(보통 | k)   = 0.45
```

- 풀이: 낮은 층에서는 쉬운 이상현상으로 규칙을 익히고, 지상에 가까울수록 어려운 것이 나와 긴장이 오름. 세 확률의 합은 항상 1
- 구현: 먼저 위 확률로 난이도를 고르고, 섞어 둔 목록에서 그 난이도의 이상현상을 하나 꺼냄. 그 난이도가 목록에 남아 있지 않으면 다른 난이도에서 꺼냄

### 6.1 예상 플레이 시간

- 루프 1회 정확도를 a라 하면, 8번 연속 정답이 나올 때까지 필요한 루프 수의 기댓값

```
E[루프 수] = (1 − a⁸) / ((1 − a) · a⁸)
```

- 풀이: "n번 연속 성공"이 처음 나올 때까지의 시행 횟수 기댓값 공식. 한 번이라도 틀리면 처음부터 다시 하므로 a가 조금만 낮아도 기댓값이 빠르게 커짐

| 정확도 a | E[루프 수] | 루프당 약 18초일 때 |
|---|---|---|
| 0.80 | 24.8 | 약 7.4분 |
| 0.85 | 17.8 | 약 5.3분 |
| 0.90 | 13.2 | 약 4.0분 |
| 0.95 | 10.1 | 약 3.0분 |

- 루프당 18초 = 운행 6초 + 문 열림·관찰 약 10초 + 버튼과 문 닫힘 약 2초 (추정). 로비 탐색이 생겨서 실제로는 더 길어질 수 있음 (확실하지 않음)
- 목표 플레이 시간 5~10분이면 평균 정확도 0.8~0.85 근처가 적당. 이상현상 난이도를 이 값에 맞춰 조정

## 7. 연출

### 7.1 운행

- 실제로 엘리베이터를 움직이지 않음. 문이 닫혀 있는 동안 로비를 바꿔 끼우고, 아래 연출로 이동을 표현
  - 출발·정지 순간 카메라가 살짝 가라앉거나 떠오름 (2.5cm)
  - 운행 중 아주 약한 진동 (약 1mm)
  - 모터 소리 (WebAudio 합성, 운행 중 음높이 변화)
  - 층 표시판 숫자 변화와 화살표
- 도착음 "딩" 한 번, 문 열림

### 7.2 추락 (오답, 시간 초과)

1. 조명이 꺼지고 비상등(붉은빛)만 남음
2. 케이블 끊기는 금속음, 화면 흔들림, 층 표시판 숫자가 빠르게 내려감
3. 충돌음과 함께 화면 암전
4. B8에서 문이 열리며, 놓친 이상현상 이름을 짧게 알려 줌

- 흔들림 (M2에서 변경): M1은 매 프레임 무작위로 최대 ±5cm씩 튀어서 어지러웠음. 지금은 서로 다른 주기의 사인파를 섞어 부드럽게 움직이고, 최대 약 1.2cm(측정값)
- 운영체제의 "동작 줄이기" 설정이 켜져 있으면 흔들림을 30%로 줄이고 걸을 때 화면 출렁임도 끔

### 7.3 놀래키는 장면 (2종)

- 관리인이 엘리베이터 안에 있음: 도착하는 순간 조명이 0.3초 꺼졌다 켜지고, 플레이어에게서 가장 먼 구석에 관리인이 서 있음. 4.5초부터 고개를 플레이어 쪽으로 돌리고, 6.2초 안에 ▼를 누르지 않으면 암전과 비명 → 처음부터
- 거울 속에만 서 있는 사람: 얼굴을 머리카락으로 가린 사람이 플레이어 반대쪽 뒷구석에서 거울을 보고 서 있음. 거울을 처음 바라보는 순간 짧은 효과음

### 7.4 엘리베이터 놓침

- 어려움 모드에서 로비에 있는 채로 문이 닫히면, 엘리베이터만 떠나는 모터 소리가 나고 로비 불이 하나씩 꺼진 뒤 암전 → B8에서 다시 시작

### 7.5 1층 엔딩

- 1F에서는 시간 제한이 없음. 엘리베이터를 걸어 나와 정면의 자동 유리문으로 가면 문이 열리고, 밖으로 나가면 화면이 하얗게 밝아지며 결말 화면
- 결말 화면: 걸린 시간, 탄 횟수, 실패 횟수, 시간 초과(놓침 포함), 발견한 이상현상(n / 27)과 이름 목록
- 결말 화면에서 다음 판의 난이도를 다시 고른 뒤 "지하 8층부터 다시"

## 8. 조작

| 동작 | PC | 터치 |
|---|---|---|
| 둘러보기 | 마우스 (포인터 고정) | 화면 오른쪽 드래그 |
| 이동 (엘리베이터 안, 문이 열려 있으면 로비까지) | WASD | 화면 왼쪽 조이스틱 |
| 버튼 누르기 (엘리베이터 안에서만) | 조준점을 버튼에 맞추고 클릭 또는 E | 버튼을 직접 탭 |

- 버튼을 조준하면 조준점이 커지고 주황색으로 바뀌며 버튼이 살짝 커짐
- 이동 속도 약 1.7m/s. 로비 끝까지(약 5m) 다녀오면 6초 정도 걸려서, 어려움 모드 12초 안에 "어디까지 확인하러 갈지"가 선택이 됨

### 9.3 M3에서 한 것

- 글씨 가독성: 화면 가운데 안내 문구를 어두운 반투명 상자 위에 더 크고 진하게 표시 (제목 21px, 아랫줄 16px). 1층처럼 밝은 배경에서도 읽히게 함. 카드의 회색 글씨도 밝고 크게
- 화질 자동 조절: 3초마다 평균 프레임을 재서 40fps 미만이면 한 단계씩 낮춤. 터치 기기는 2단계에서 시작

| 단계 | 화면 해상도 배율 상한 | 거울 해상도 (화면 대비) |
|---|---|---|
| 1 | 1.75 | 0.6 |
| 2 | 1.25 | 0.45 |
| 3 | 1.0 | 0.3 |

- 누적 기록 (v0.6부터 난이도별로 따로 저장. 결말 화면에서 난이도를 골라 봄. 방금 한 난이도가 먼저 보임): 결말 화면의 "누적 기록"에서 이상현상별 맞힘/만남(발견률 낮은 순), 정상 층에서 ▼를 누른 비율(오탐률), 시간 초과 비율, 완주 횟수를 볼 수 있음
  - 이 브라우저의 localStorage에만 저장. 서버로 보내지 않음. "기록 지우기"로 초기화
  - 10장의 지표를 실제로 모으는 도구. 여러 판을 한 뒤 발견률이 20% 미만이거나 95% 초과인 이상현상부터 조정
- 일시정지 (v0.6): 화면 오른쪽 위 "일시정지" 버튼(휴대폰에서도 가능) 또는 PC의 Esc. "계속하기" 또는 "난이도 선택하기"
  - 난이도를 고르는 동안에는 진행 중인 판의 난이도를 바꾸지 않음. "이 난이도로 지하 8층부터"를 누르면 새 판으로 시작
  - 판 중간에 난이도를 바꾸지 않는 이유: 이상현상 확률과 시간 제한이 섞이면 누적 기록과 공정성이 흐려짐
- 터치 조작 검증 (휴대폰 흉내 모드): 조이스틱으로 문간을 지나 로비까지 이동, 화면 끌어 시점 회전, 버튼 탭

## 10. 플레이테스트에서 볼 지표

- 이상현상별 발견률 = 맞게 ▼를 누른 횟수 / 등장 횟수
  - 20% 미만: 너무 안 보임 → 크기·대비를 키우거나 쉬운 단서 추가
  - 95% 초과: 너무 쉬움 → 난이도를 낮게 재분류하거나 미묘하게 수정
- 오탐률 = 정상 루프에서 ▼를 누른 비율. 높으면 정상 상태에 "이상해 보이는" 소품이 있다는 뜻
- 시간 초과 비율 (어려움 모드, 놓침 포함). 결말 화면의 "시간 초과" 칸으로 바로 볼 수 있음
  - 높으면 문 열림 시간이 짧다는 뜻. `?open=` 값을 바꿔 가며 비교
