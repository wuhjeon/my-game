# 끝없는 통로

같은 지하 통로가 반복되는 1인칭 "이상현상 찾기" 공포 탈출 게임. `index.html` 하나로 동작한다 (Three.js r128, CDN).

## 규칙
- 통로에 이상한 점이 있으면 되돌아가고(시작 지점 왼쪽 통로), 없으면 끝까지 가서 오른쪽 통로로 나간다.
- 맞히면 출구 번호 +1, 틀리면 0으로 초기화. 8이 되면 탈출.
- 첫 통로는 항상 정상이므로 기준 모습을 기억해 둔다.

## 조작
- PC: WASD 이동, Shift 달리기, 마우스 시점(클릭 시 포인터 고정), M 소리, Esc 일시정지
- 터치: 화면 왼쪽 드래그 이동(끝까지 밀면 달리기), 오른쪽 드래그 시점

## 이상현상 (19종)
포스터 속 눈, 좌우 반전 포스터, 늘어난 포스터, 붉은 조명, 깜빡이는 조명, 열린 문, 사라진 소화기,
빠르게 도는 시계, 거대한 남자, 멈춰서 쳐다보는 남자, 뒤로 걷는 남자, 남자가 없음, 떨어지는 피,
벽의 손자국, 반대를 가리키는 출구 표지판, 내려오는 천장, 따라보는 감시 카메라, 붉은 점자 블록,
다가오는 그림자(붙잡히면 0으로 초기화)

## 실행
브라우저로 `index.html`을 열면 된다. 로컬 서버가 필요 없다.
